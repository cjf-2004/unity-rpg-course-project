# Unity RPG Course Project

Unity 3D 异世界 RPG 课程项目的核心脚本归档，共 59 个 C# 文件、约 6,682 行代码。

## 系统组成

- `Player` / `Combat`：角色移动、视角、普通攻击、闪避、属性成长、伤害判定和战斗区域。
- `AI`：野猪、野兔和士兵三类战斗 AI，以及 NPC 闲置、巡逻和对话状态。
- `Inventory`：材料、消耗品、武器与护甲分类，装备、金币、拾取、掉落和属性展示。
- `Dialog` / `Story`：基于 ScriptableObject 的分支对话，以 UnityEvent 串联剧情节点和任务提示。
- `Global`：玩家、背包与剧情进度存档，异步场景加载及全局数据管理。
- `UI`：战斗 HUD、受击/死亡反馈、物品提示、任务提示和菜单。

## 个人工作

课程项目中主要负责核心玩法与系统脚本的实现和联调，包括玩家战斗、敌人 AI、背包、分支对话、剧情事件、存档与场景加载。仓库按源码模块保留，便于查看系统拆分和代码组织。

仓库只包含课程工程中的 `Assets/Scripts` 源码，不包含 Unity 工程、商用/第三方模型材质、音频、贴图或其他付费资产。完整工程需要在获得相应资产授权后恢复；脚本不能单独保证开箱即用。
